01 // WHAT IT IS

A declarative port of Ryoku.

Ryoku on NixOS brings the Ryoku desktop to a reproducible NixOS system without changing what makes Ryoku feel like Ryoku.

01

Same desktop.

Hyprland, the Ryoku shell, theming, lockscreen, Hub, helpers and desktop experience.

02

Nix underneath.

Normal NixOS generations, flake inputs, rollback, and declarative integration.

03

No fake distro tricks.

Ryoku does not repartition your drives, replace your bootloader, or own your GPU setup.

02 // INSTALL

Three steps in.

Built for people who are new to NixOS. No assumed wizardry.

01Enable flakes

Add this inside /etc/nixos/configuration.nix:

nix.settings.experimental-features = [
  "nix-command"
  "flakes"
];
sudo nixos-rebuild switch
02Make NixOS flake-based

Create /etc/nixos/flake.nix and rebuild from it.

sudo nixos-rebuild switch --flake /etc/nixos#nixos
Need the beginner flake example →
03Install Ryoku

Preview first if you want:

nix run github:aethctl/Ryoku-on-NixOS/main#install -- --dry-run

Then install:

nix run github:aethctl/Ryoku-on-NixOS/main#install

03 // FAQ

Common questions.

How do I enable flakes?

Add the following to /etc/nixos/configuration.nix, then rebuild:

nix.settings.experimental-features = [
  "nix-command"
  "flakes"
];
sudo nixos-rebuild switch
What should a basic flake.nix look like? 
{
  description = "My NixOS system";

  inputs.nixpkgs.url = "github:NixOS/nixpkgs/nixos-26.05";

  outputs = { nixpkgs, ... }: {
    nixosConfigurations.nixos = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [ ./configuration.nix ];
    };
  };
}
How do I update Ryoku? 
ryoku update

That's it. Ryoku updates its configured flake input, builds a new NixOS generation and switches to it.

Does Ryoku replace NixOS?

No. Ryoku integrates into your existing NixOS configuration. Your bootloader, kernel, disks and graphics configuration remain owned by your NixOS system.

What if an update breaks?

Ryoku updates create normal NixOS generations. Previous generations remain available through standard NixOS rollback and boot-menu mechanisms.

Where does Ryoku back up my configuration? 
/var/backups/ryoku-nixos/
