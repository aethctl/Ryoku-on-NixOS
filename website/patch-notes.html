LATEST // CURRENT NIXOS PORT

0.60.1
BETA.19

RYOKU ON NIXOS
UPDATE PATCH NOTES

This update brings Ryoku on NixOS up to v0.60.1-beta.19, adding the latest upstream features while fixing several NixOS-specific issues found during testing/ bug reporting.

✨

Features added

  • Parallax Wallpapers with layered foreground/background effects and multi-monitor support
  • Parallax tab added beside Depth in Quick Settings
  • KDE colour integration allowing KDE apps to follow Ryoku/Matugen themes
  • Music visualizers now automatically update colours with your wallpaper
  • Improved visualizer rotation and edge positioning
  • Improved HDMI/TV monitor persistence
  • Power profiles now persist more reliably between sessions
  • Ghostty now keeps your personal configuration when Ryoku updates its theme
  • Full visible shell/widget parity with the latest upstream Ryoku
🛠️

Bug Fixes

  • Fixed Ryogami wallpaper UI failing to open on NixOS
  • Fixed Qt/QuickShell incompatibilities which could break wallpaper previews and multimedia features
  • Fixed Parallax not appearing automatically for users upgrading from older Ryoku versions
  • Fixed HDMI displays and TVs losing saved monitor settings after connector changes
  • Fixed wallpaper/theme changes not updating the now-playing spectrum correctly
  • Fixed Ghostty theme updates overwriting user settings
  • Fixed power profile state being lost unexpectedly
  • Removed outdated Spotify/Spicetify integration and leftover packaging
  • Fixed several NixOS packaging, service and dependency issues discovered during the 0.60 port
🧹

Changes

  • Spotify and Spicetify are no longer bundled or managed by Ryoku
  • Ryoku's Qt and QuickShell components are now kept on the same locked version to prevent compatibility issues
⁉️

Known Issues

  • Ryotunes Spotify doesnt work as intended (This song is not avaliable on spotify errors on every song), this is not a bug with NixOS and simply an upstream bug from the main repo
ARCHIVE // MUSUBI

MUSUBI
0.58.6

結び
BETA.19

Musubi, (meaning to tie together in Japanese) updates Ryoku on NixOS from 0.48.8-beta.18 → 0.58.6-beta.19.

✨

Features added

  • Ryogami wallpaper engine with live wallpapers, shaders, transitions, playlists and multi-monitor support
  • Depth Wallpapers fully integrated into Ryogami
  • Ryotunes with MPRIS and playerctl support
  • Ryoport with Looking Glass and optional GPU passthrough
  • Plugin system with install, validate, remove, export and QS Bar integration
  • QS Bar overhaul with persistent layouts, widget catalogue and improved Control Center
  • Rashin upgrades with packaged skills and Prowl code intelligence
  • New NixOS installer with dry runs, backups, rollback and safe flake editing aswell as finally fully supporting NixOS stable
  • Native Nix update backend
  • Declarative GPU passthrough module
  • New keyboard OSD, widgets, launcher actions and visual improvements
🛠️

Bug Fixes

  • Fixed Arch-only pacman, AUR and system management behaviour on NixOS
  • Fixed Doctor attempting unsafe Arch-specific repairs
  • Fixed update/version detection for local NixOS checkouts
  • Fixed SDDM theme switching and Polkit integration
  • Fixed Rashin skills not being packaged or detected
  • Fixed Rashin incorrectly identifying NixOS as Arch
  • Fixed Ryogami/Depth paths, renderer cleanup and multi-monitor behaviour
  • Fixed RyoVM help commands and missing xorriso
  • Fixed GPU passthrough being exposed before the host is configured
  • Fixed plugin install, discovery and cleanup issues
  • Fixed installer host detection and flake parsing edge cases
  • Fixed Git hooks failing on NixOS due to /bin/bash
  • Numerous additional NixOS path, service and dependency fixes
✅ Fully tested on my main PC and Testing laptop
